Этапы работы

Состав технического задания

Для выполнения визуализации необходимо предоставить техническое задание, в которое должны входить:

  • План с расстановкой мебели (формат PDF, DWG).
  • Обмерный план.
  • План полов с напольными покрытиями, потолков, осветительных приборов, электрики и электроприборов.
  • Текстовый файл с описанием всех отделочных материалов и элементов дизайна (с ссылками, иллюстрациями, моделями).
  • Чертежи для моделирования нестандартной корпусной мебели.
  • Текстовый файл с подборкой мебели/моделей c 3ddd.ru или на сайт производителя, с возможностью скачать 3д модель.
  • Фото вида из окна (или описание вида).
  • Ваши пожелания по формату и пропорций рендеров.
  • Развертки помещений с размерами и с указанием отделочных материалов.
  • Примеры или пожелания по декору.
  • Ссылки на отделочные материалы пола, стен, потолка, цвет оконных рам, дверей. (Указание цвета по Ral / Ncs и тД.).
